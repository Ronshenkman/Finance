# שקל-קל | מעקב הוצאות ויעדים חכמים (Shekel-Kal)

אפליקציית רשת (Web App) מעוצבת, מודרנית ואינטראקטיבית למעקב אחר הוצאות שוטפות וניהול יעדי תקציב חודשיים לפי קטגוריות. האפליקציה כתובה בעברית עם תמיכה מלאה בכיווניות ימין לשמאל (RTL).

## 🚀 תכונות עיקריות

- **לוח בקרה חכם (Dashboard)**: צפייה בסיכום התקציב הכללי, מד ניצול חזותי דינמי (טבעת התקדמות) ויתרת תקציב פנוי.
- **ניהול קטגוריות מובנה**:
  - מגיע מוכן עם 6 קטגוריות מובנות: **קבועים**, **מזון**, **אוכל בחוץ**, **בגדים**, **פארמה**, ו**חד פעמי**.
  - אפשרות ליצירת קטגוריות חדשות עם בחירת אמוג'י, צבע נושא מותאם אישית ותקציב יעד חודשי.
  - עדכון מהיר של יעד התקציב ישירות מהכרטיסייה (בלחיצה על סכום היעד).
- **מדדי התקדמות צבעוניים**: כרטיסי הקטגוריות מחשבים אוטומטית את אחוזי הניצול ומשנים את צבעם בהתאם לסטטוס (ירוק לבטוח, צהוב להתקרבות לגבול, ואדום לחריגה מהתקציב).
- **ניתוח נתונים ויזואלי (Charts)**: גרפים אינטראקטיביים המבוססים על Chart.js המציגים:
  - התפלגות הוצאות באחוזים לפי קטגוריות (גרף דונאט).
  - מגמת הוצאות יומית לאורך 14 הימים האחרונים (גרף קו רציף).
- **רישום עסקאות מפורט**: טבלה מסודרת של ההוצאות השוטפות המאפשרת חיפוש חופשי לפי תיאור, סינון מהיר לפי קטגוריה ומחיקת עסקאות שמחשבת מחדש את כל המדדים.
- **שמירת נתונים מקומית (LocalStorage)**: הנתונים נשמרים בדפדפן באופן אוטומטי ומאובטח, ללא צורך ברישום או בשרת חיצוני.

## 🛠️ טכנולוגיות

- **HTML5** - מבנה סמנטי ותמיכה ב-RTL.
- **CSS3 (Vanilla)** - עיצוב מודרני מבוסס Glassmorphism, משתני CSS, אנימציות ופריסת גריד/פלקס רספונסיבית למובייל ומחשב.
- **JavaScript (ES6+)** - ניהול מצב (State) מקומי, עדכוני DOM דינמיים וטיפול באירועים.
- **Chart.js** - ספריית גרפים קלילה ומעוצבת מ-CDN.

## 💻 הרצה מקומית

הפרויקט הינו סטטי לחלוטין ואינו דורש שרתי backend מורכבים. 

### אפשרות א': הרצה מהירה
פשוט פתח את הקובץ `index.html` ישירות בדפדפן שלך.

### אפשרות ב': הרצה כשרת פיתוח מקומי (מומלץ)
אם ברצונך להריץ שרת מקומי קטן (למשל, כדי להימנע מבעיות CORS מקומיות בפיתוח עתידי):
1. ודא שמותקן אצלך [Node.js](https://nodejs.org/).
2. בתיקיית הפרויקט, התקן את התלויות והפעל את שרת הפיתוח:
   ```bash
   npm install
   npm run dev
   ```
3. פתח את הדפדפן בכתובת: `http://localhost:3000`

## 🌐 העלאה ל-GitHub Pages (אירוח חינם)

מכיוון שהאתר בנוי כדפי אינטרנט סטטיים, קל מאוד להעלות אותו ל-**GitHub Pages** תוך דקה:
1. צור מאגר (Repository) חדש ב-GitHub והעלה אליו את קבצי הפרויקט (`index.html`, `style.css`, `app.js`, `.gitignore`, `package.json`, `README.md`).
2. כנס להגדרות המאגר ב-GitHub: **Settings > Pages**.
3. תחת **Build and deployment**, בחר במקור (Source) כ-**Deploy from a branch**.
4. בחר בענף הראשי **main** (או `master`) ותיקיית השורש `/ (root)`.
5. לחץ **Save**. האתר שלך יהיה זמין באוויר תוך דקה בכתובת: `https://your-username.github.io/your-repo-name/`
